What a limit covers

Daily app quotas count downloaded and uploaded bytes while Flow runs. Upload rate limits use Windows QoS; they do not cap download speed. Rules are checked about every 5 seconds, so a fast transfer can exceed a quota slightly.

Recovery

Normal shutdown releases Flow's network controls. If Flow crashes, a Windows block can remain. Run Restore Access.cmd or use Restore all app access. Other firewall rules are never removed.

Collection & privacy

Live application capture

Launch Start Monitor.cmd and approve Windows elevation to enable per-application traffic collection. Adapter totals are available without administrator access.

Waiting for collector status.

Local history

Usage is collected and stored on this laptop while the monitor runs. Flow cannot reconstruct traffic from before collection started or while it was stopped. App counters measure kernel TCP/IP traffic and may differ from physical-adapter totals, especially with a VPN.

Pausing the display

Pause display freezes the dashboard only. The local service continues collecting usage and history.

Optional router access

The router connection is read-only. Credentials stay in service memory for the connection. Whole-network totals are shown separately from laptop usage.

Stop collection

Shut down the local monitor service. Collection and history stop until you launch Start Monitor.cmd again.
